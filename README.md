# TripPlanner

Веб-приложение для совместного планирования путешествий: участники создают поездки, предлагают места, голосуют за них, составляют таймлайн, учитывают расходы и общаются в чате.

## Технологии

- Клиент: React, TypeScript, Tailwind CSS, Leaflet, Socket.IO Client.
- Сервер: Node.js, Express, TypeScript, Socket.IO.
- База данных: MySQL.

## Возможности

- Регистрация и вход по JWT.
- Создание поездок и управление участниками по приглашению.
- Места на карте, голосование и планирование времени посещения.
- Учёт общих расходов, долей и итогового баланса.
- Чат участников поездки в реальном времени.

## Запуск

1. Создайте базу и заполните тестовыми данными:

   ```bash
   mysql -u root -p < database/schema.sql
   mysql -u root -p trip_planner < database/seed.sql
   ```

2. Скопируйте `server/.env.example` в `server/.env`, задайте параметры MySQL и надёжный `JWT_SECRET`.
3. При необходимости скопируйте `client/.env.example` в `client/.env` и укажите адреса развернутого API.
4. В отдельных терминалах выполните:

   ```bash
   cd server && npm install && npm run dev
   cd client && npm install && npm start
   ```

Клиент по умолчанию доступен по `http://localhost:3000`, API — по `http://localhost:5000/api`.

## Проверка сборки

```bash
cd server && npm run build
cd client && npm run build
```

## Ограничения безопасности

Все операции с поездками, местами, расходами и чатом проверяют участие пользователя в поездке. Приглашение может принять только пользователь с email, для которого оно создано.
